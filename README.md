# Crosspost Composer

A WordPress plugin that adds a **Crosspost** panel to the block editor. It suggests a short post text from the title and content, lets you edit it, and opens the web composer of X, Bluesky, Threads, Mastodon, LinkedIn or Facebook with that text filled in. You publish there, as yourself. No API keys, no connected accounts.

See [readme.txt](readme.txt) for the full description, FAQ and changelog.

## Requirements

WordPress 6.5 or newer, PHP 7.4 or newer.

## Installation

Copy this folder to `wp-content/plugins/crosspost-composer` and activate it. Services and the Mastodon instance are configured under Settings > Crosspost.
